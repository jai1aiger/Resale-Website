# ReLoop | Premium Resale Marketplace

ReLoop is a modern, professional peer-to-peer resale marketplace frontend. It is designed to facilitate high-conversion buying and selling of vintage fashion, tech, and lifestyle goods.

## 🚀 Live Demo & Showcase
The platform can be previewed locally. Simply open `index.html` in any browser or run a simple local server.

## 🎨 Design System & Color Theory
ReLoop leverages modern color psychology tailored for the circular economy:
- **60% Dominant (Canvas):** `#FAF9F6` (Alabaster Linen) - Creates a clean, premium backdrop that makes product images pop.
- **30% Secondary (Structure):** `#2D2B2A` (Espresso Black) - Used for primary headings, navigation structure, and solid buttons.
- **10% Accent (Call to Action):** `#D96B43` (Terracotta/Burnt Orange) - Highlights prices, sale badges, checkout actions, and listing triggers.

## ⚡ Core Features
1. **Interactive Product Feed:** Filter listings by category or search by item keywords instantly.
2. **Sell an Item Simulator:** Users can list their own items for resale. Adding an item updates the listing grid dynamically in real-time.
3. **Responsive Cart Drawer:** Slides in from the right to review items, quantities, and check out.
4. **Mock Checkout Funnel:** Processes orders, validates checkout forms, and returns reference IDs.
